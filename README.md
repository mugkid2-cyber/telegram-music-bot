# Telegram Music Bot - Деплой на Render

Telegram бот для скачивания и воспроизведения музыки с поддержкой YouTube, VK, и других платформ.

## 🚀 Быстрый деплой на Render (бесплатно)

### Возможности бота:
- 🎵 Скачивание музыки с YouTube, VK и других платформ
- ⭐ Избранные треки
- 🎂 Напоминания о днях рождения
- 💬 Создание цитат из сообщений
- 🎤 Распознавание музыки (Shazam)

### Что было отключено для оптимизации:
- Триггеры на имена (Иван и т.д.)
- Триггер группы "Нервы"
- Автоматический калькулятор
- Автоматический переводчик
- Команды удаления сообщений (/cms)
- Помощь в принятии решений (/choice, /yesno, /dice)
- Случайный контент (/fact, /motivation, /tip)
- Напоминания (/remind, /timer)
- Генератор паролей (/genpass, /genpin)
- Инструменты работы с текстом (/count, /reverse, /upper)
- Информация о пользователях (/id, /me, /ping)
- Конвертер единиц (/convert)
- Опросы (/poll, /quiz)
- QR-коды (/qr, /barcode, /link)

## 🔧 Инструкция для новичков

### Шаг 1: Получение токена бота

1. Откройте Telegram
2. Найдите [@BotFather](https://t.me/BotFather)
3. Отправьте команду `/newbot`
4. Введите имя бота (например: "My Music Bot")
5. Введите username бота (например: "my_music_bot")
6. **Скопируйте токен** (выглядит так: `1234567890:ABCdefGHIjklMNOpqrsTUVwxyz`)
7. Сохраните токен - он понадобится позже!

### Шаг 2: Создание репозитория на GitHub

1. Зарегистрируйтесь на [GitHub](https://github.com/signup) (если ещё нет аккаунта)
2. Нажмите на зелёную кнопку **"New"** (или перейдите на https://github.com/new)
3. Заполните форму:
   - **Repository name**: `telegram-music-bot` (или любое другое имя)
   - **Description**: "Telegram music bot for Render"
   - Выберите **Public** (публичный репозиторий)
   - ✅ Поставьте галочку **"Add a README file"**
4. Нажмите **"Create repository"**
5. Запомните адрес репозитория (например: `https://github.com/ваш-username/telegram-music-bot`)

### Шаг 3: Загрузка кода на GitHub

Выполните следующие команды в папке с ботом:

```bash
cd C:/Users/ПК/Downloads/SOLO

# Инициализация Git (если ещё не сделано)
git init

# Добавление файлов
git add .

# Создание коммита
git commit -m "Initial commit: Telegram Music Bot for Render"

# Добавление удалённого репозитория (замените на ваш URL)
git remote add origin https://github.com/ваш-username/telegram-music-bot.git

# Отправка кода на GitHub
git branch -M main
git push -u origin main
```

**Важно:** При первом push GitHub попросит ввести логин и пароль. Вместо пароля используйте **Personal Access Token**:
1. Перейдите на https://github.com/settings/tokens
2. Нажмите **"Generate new token"** → **"Generate new token (classic)"**
3. Назовите токен: `Render Deploy`
4. Поставьте галочку **repo** (полный доступ к репозиториям)
5. Нажмите **"Generate token"**
6. Скопируйте токен и используйте его вместо пароля

### Шаг 4: Регистрация на Render

1. Перейдите на [Render](https://render.com)
2. Нажмите **"Get Started for Free"**
3. Зарегистрируйтесь через **GitHub** (самый простой способ)
4. Разрешите Render доступ к вашим репозиториям

### Шаг 5: Создание Web Service на Render

1. В панели Render нажмите **"New +"** → **"Background Worker"**
2. Подключите ваш репозиторий:
   - Найдите `telegram-music-bot` в списке
   - Нажмите **"Connect"**
3. Заполните настройки:
   - **Name**: `telegram-music-bot` (или любое имя)
   - **Region**: `Frankfurt (EU Central)` (ближайший к вам)
   - **Branch**: `main`
   - **Runtime**: **Python 3**
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python -m app.bot`

### Шаг 6: Настройка переменных окружения

Прокрутите вниз до раздела **"Environment Variables"** и добавьте:

| Ключ | Значение | Описание |
|------|----------|----------|
| `BOT_TOKEN` | `ваш_токен_от_BotFather` | Токен бота |
| `FFMPEG_PATH` | `/usr/bin/ffmpeg` | Путь к FFmpeg на Render |
| `DATABASE_PATH` | `app/data/bot.db` | Путь к базе данных |
| `DOWNLOAD_DIR` | `app/media/audio/cache` | Папка для загрузок |

**Остальные переменные использовать значения по умолчанию из `.env.example`**

### Шаг 7: Деплой!

1. Нажмите **"Create Background Worker"** внизу страницы
2. Render начнёт деплой (это займёт 3-5 минут)
3. Следите за логами в разделе **"Logs"**
4. Когда увидите `"Бот запущен и готов к работе"` - всё готово! ✅

### Шаг 8: Проверка работы

1. Откройте Telegram
2. Найдите вашего бота по username
3. Отправьте `/start`
4. Бот должен ответить главным меню!

## 🎵 Основные команды

- `/start` - Главное меню и инструкции
- `/fav` - Показать избранные треки
- `/bdl` - Список дней рождения в чате
- `/qt` - Создать цитату из сообщения (ответьте на сообщение)

## ⚠️ Важные замечания

### Бесплатный план Render:
- ✅ 750 часов работы в месяц (достаточно для одного бота 24/7)
- ✅ Автоматический деплой при push в GitHub
- ✅ HTTPS и SSL из коробки
- ⚠️ Бот "засыпает" после 15 минут неактивности (автоматически просыпается при новом сообщении)
- ⚠️ Диск очищается при каждом деплое (база данных сохраняется только в памяти)

### Для продакшн-использования:
- Используйте внешнюю БД (PostgreSQL от Render или другой сервис)
- Храните медиа-файлы в S3 или другом облачном хранилище
- Рассмотрите платный план для стабильной работы 24/7

## 🐛 Решение проблем

### Бот не отвечает:
1. Проверьте логи на Render
2. Убедитесь, что токен бота правильный
3. Проверьте, что сервис запущен (статус "Running")

### Ошибка при деплое:
1. Проверьте `requirements.txt` - все ли зависимости указаны
2. Проверьте логи сборки (Build Logs)
3. Убедитесь, что используется Python 3.11

### База данных не сохраняется:
- На бесплатном плане Render диск эфемерный
- Используйте внешнюю БД (PostgreSQL) для постоянного хранения
