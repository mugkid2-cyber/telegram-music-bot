# Модуль «Цитатник» (`app/quotes/`)

Бот собирает N сообщений вниз от отмеченного (`/qt N`, алиас `/q N`, как на
скриншоте), рендерит их в карточку в стиле мессенджера и добавляет как
стикер в стикерпак **этого чата**. `/qdel` (только для админов группы) —
удаляет стикер-цитату из пака и записи из БД. Раз в сутки бот сам присылает
случайную цитату из пака чата.

## Стек
`aiogram 3.x` · `SQLAlchemy 2.0 (async, aiosqlite)` · `Pillow` · `APScheduler`

```
pip install aiogram SQLAlchemy aiosqlite Pillow APScheduler
```

## Структура

```
app/quotes/
├── models.py          # MessageLog, QuoteStickerPack, Quote
├── db.py              # engine/session (замените на общий, если он уже есть)
├── message_log.py      # запись сообщений + выборка окна для /qt
├── middleware.py        # логирует каждое сообщение чата
├── colors.py            # цвет имени пользователя (детерминированный)
├── renderer.py           # рендер PNG-карточки цитаты (Pillow)
├── sticker_pack.py        # создание/пополнение стикерпаков, part-ротация
├── handlers.py             # /qt, /qdel
├── scheduler.py             # ежедневная случайная цитата
└── assets/fonts/             # DejaVu Sans (кириллица) — уже включены
```

## Как это работает

### Журналирование (`middleware.py`, `message_log.py`)
Bot API не отдаёт произвольное сообщение чата по id, поэтому **любое**
сообщение группы логируется в `quotes_message_log` через middleware. `/qt N`
ищет в этом журнале анкорное сообщение и до `N` следующих по возрастанию
`message_id` (лимит `MAX_WINDOW = 10`, меняется в `message_log.py`). Если
сообщение отправлено до подключения бота — оно просто отсутствует в
журнале, и `/qt` на него ответит, что процитировать не получится.

⚠️ **Если в проекте уже есть похожий middleware** (в ТЗ упомянут аналог для
учёта участников чата) — не подключайте второй, а добавьте вызов
`log_message()` из `message_log.py` в него.

### Стикерпаки (`sticker_pack.py`)
На чат заводится отдельный пак `quotes_c<chat_id>_p1_by_<bot_username>`.
Telegram ограничивает один пак 120 стикерами — при достижении лимита
модуль автоматически создаёт `..._p2_by_...` и т.д. (в БД это разные строки
`QuoteStickerPack` с одним `chat_id` и разным `part_number`).

Владельцем пака в Telegram API указывается пользователь, вызвавший `/qt`
первым в чате (`user_id` в `createNewStickerSet`) — это требование самого
API (сет должен на кого-то оформляться), но управляет им (добавляет/удаляет
стикеры) всегда бот, независимо от того, кто выполняет команды.

### Рендер (`renderer.py`)
Карточка — тёмный скруглённый прямоугольник, подряд идущие сообщения
одного автора группируются под одним аватаром/именем (как quote-боты
в примере на скриншоте). Ширина фиксированная (480px + паддинги),
итоговое изображение приводится к требованиям Telegram для статичных
стикеров (одна сторона ровно 512px). Шрифт DejaVu Sans уже лежит в
`assets/fonts/` — кириллицу поддерживает из коробки, ничего скачивать не
нужно.

### `/qdel`
Разрешён только администраторам/создателю чата (проверка через
`getChatMember`). Нужно ответить командой на сам стикер-цитату — бот ищет
запись по `file_unique_id` этого стикера, вызывает `deleteStickerFromSet`
и удаляет запись из БД.

### Ежедневная цитата (`scheduler.py`)
`setup_quote_scheduler(scheduler, bot)` регистрирует cron-джобу в
переданном `AsyncIOScheduler`. Если в проекте уже есть общий scheduler
(вероятно, используется в `app/bday/` для поздравлений) — переиспользуйте
его инстанс, не создавайте второй. Время по умолчанию — 12:00 по времени
сервера, меняется константами `DAILY_HOUR` / `DAILY_MINUTE` в начале файла.

## Подключение в точке входа бота

```python
from aiogram import Bot, Dispatcher
from apscheduler.schedulers.asyncio import AsyncIOScheduler

from app.quotes import quotes_router, QuoteLoggingMiddleware, setup_quote_scheduler
from app.quotes.db import init_models  # если используете свой db.py — пропустите

async def main():
    bot = Bot(token=BOT_TOKEN)
    dp = Dispatcher()

    await init_models()  # создать таблицы модуля (один раз при старте)

    dp.message.middleware(QuoteLoggingMiddleware())
    dp.include_router(quotes_router)

    scheduler = AsyncIOScheduler()
    setup_quote_scheduler(scheduler, bot)
    scheduler.start()

    await dp.start_polling(bot)
```

## Что стоит проверить перед продакшеном (я собирал это без доступа
к вашему репозиторию и без интернета в песочнице — не смог прогнать
код против настоящего Telegram Bot API):

1. **Общая БД.** Если в проекте уже есть общий `Base`/engine — уберите
   `app/quotes/db.py`, зарегистрируйте `models.py` в общей metadata и
   прогоните миграцию (Alembic или ваш штатный механизм).
2. **Общий scheduler/middleware** — см. предупреждения выше, чтобы не
   плодить вторые инстансы.
3. **Права бота.** Для создания/редактирования стикерпаков и удаления
   стикеров боту не нужны особые права в самом чате, но `getUserProfilePhotos`
   и работа со стикерпаками требуют, чтобы это был обычный Bot API токен
   (не Business-аккаунт с ограничениями).
4. **username бота обязателен** (используется в имени пака) — если у бота
   его нет, `create_new_sticker_set` в `sticker_pack.py` упадёт с assert.
5. Реальный размер PNG-карточки после рендера стоит на всякий случай
   визуально проверить на паре длинных цитат (5-10 сообщений) — авто-сжатие
   в WEBP при превышении 512KB в `renderer.py` работает, но не тестировалось
   на живых данных.
