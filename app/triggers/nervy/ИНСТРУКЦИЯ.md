# 🎵 ИНСТРУКЦИЯ: Как добавить треки группы Нервы

## Шаг 1: Подготовка треков

Скачайте треки группы Нервы в формате MP3 с метаданными:
- Название трека (обязательно)
- Исполнитель: "Нервы"
- Обложка (желательно встроенная в MP3)

## Шаг 2: Размещение файлов

Поместите все MP3 файлы в папку:
```
C:\SOLOO\SOLO\app\triggers\nervy\audio\
```

### Формат названий файлов (рекомендуется):
```
Батареи.mp3
Кофе мой друг.mp3
Слишком влюблён.mp3
Самый дорогой человек.mp3
Лід.mp3
```

## Шаг 3: Добавление обложек (опционально)

Если в MP3 нет встроенной обложки, добавьте JPG файлы с таким же именем:
```
Батареи.mp3  →  Батареи.jpg
Кофе мой друг.mp3  →  Кофе мой друг.jpg
```

## Шаг 4: Запуск бота

```bash
python -m app.bot
```

Бот автоматически найдёт все треки и будет готов к работе!

## Проверка

После запуска в логах должно быть:
```
✨ Инициализация триггера Нервы
✨ Найдено треков в папке audio: 25
```

## Как это работает

### Триггер активируется на слова:
- нервы, Нервы, НЕРВЫ
- nervy, Nervy, NERVY  
- нерв, нервов, нервами

### Поведение:
- Отправляет случайный трек без повторений
- После проигрывания всех треков история сбрасывается
- Читает название из ID3 тегов MP3
- Если тегов нет, использует имя файла

## Рекомендации по качеству

✅ **Хорошо:**
- MP3 с битрейтом 192-320 kbps
- ID3v2.3 или ID3v2.4 теги
- Встроенная обложка 600x600px или выше
- Чистые студийные записи

❌ **Плохо:**
- Концертные записи
- Низкое качество (<128 kbps)
- Файлы без метаданных
- Каверы других исполнителей

## Количество треков

Добавьте столько треков, сколько хотите!
- Минимум: 1 трек
- Рекомендуется: 20-50 треков
- Максимум: без ограничений

Чем больше треков, тем интереснее будет использовать бота! 🎧
