# Триггер Нервы

Автоматическая отправка треков группы Нервы при упоминании в чате.

## Структура

```
app/triggers/nervy/
├── __init__.py          # Экспорты модуля
├── nervy_trigger.py     # Основная логика триггера
├── audio/               # 📁 Папка для MP3 файлов (добавьте сюда треки)
└── README.md            # Эта инструкция
```

## Как добавить треки

1. **Скачайте треки группы Нервы** в формате MP3
2. **Поместите файлы** в папку `app/triggers/nervy/audio/`
3. **Название файлов** может быть любым, но желательно:
   - `Батареи.mp3`
   - `Кофе мой друг.mp3`
   - `Слишком влюблён.mp3`
   - и т.д.

## Обложки (опционально)

Для красивого отображения добавьте обложки:
- Формат: JPG
- Имя: такое же как у трека
- Пример: `Батареи.mp3` + `Батареи.jpg`

## Как работает

### Детекция
Триггер активируется при упоминании слова "нервы" в любом регистре:
- `нервы`, `Нервы`, `НЕРВЫ`
- `nervy`, `Nervy`, `NERVY`
- `нерв`, `нервов`, `нервами`

### Отправка треков
- Случайный выбор без повторений
- После проигрывания всех треков история сбрасывается
- Автоматическое извлечение названия из метаданных MP3
- Fallback на имя файла если метаданных нет

## Пример использования

**В чате:**
```
Пользователь: Слушаю сейчас нервы
Бот: [отправляет случайный трек с обложкой]
```

## Логирование

```
✨ Инициализация триггера Нервы
✨ Найдено треков в папке audio: 25
✨ Отправка трека: Батареи, осталось неиграных: 24/25
```

## Технические детали

- **Формат:** MP3 с ID3 тегами
- **Метаданные:** Читаются через библиотеку mutagen
- **История:** Хранится в памяти (сбрасывается при перезапуске)
- **Обложки:** JPG файлы с таким же именем как трек
