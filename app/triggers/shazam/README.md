# 🎵 Shazam Module

Модуль распознавания музыки для Telegram бота.

## 🎯 Возможности

- 🎤 Распознавание из голосовых сообщений
- 🎵 Распознавание из аудио файлов
- 🎬 Распознавание из видео
- ⭕ Распознавание из видео-кружков
- 📄 Распознавание из документов (аудио)

## 📝 Использование

**Как использовать:**
1. Кто-то отправляет сообщение с музыкой (голосовое/видео/аудио)
2. Ты отвечаешь на это сообщение словом: **шазам**
3. Бот распознаёт трек и выдаёт всю информацию
4. Бот автоматически находит полную версию для скачивания!

**Примеры:**
- Ответь "шазам" на голосовое
- Ответь "Шазам" на видео (регистр не важен)
- Ответь "ШАЗАМ" на аудио файл

## 📊 Что показывает

После распознавания бот покажет:
- 🎤 Исполнитель
- 🎶 Название трека
- 💿 Альбом (если есть)
- 🎭 Жанр
- 📅 Год выпуска
- ⏱️ Длительность
- 🖼️ Обложка альбома
- 🔗 Ссылки (Shazam, Apple Music)
- ✅ Кнопки для скачивания полной версии

## ⚙️ Технические детали

**Зависимости:**
- `shazamio` - библиотека для распознавания

**Установка:**
```bash
pip install shazamio
```

**Ограничения:**
- Максимальный размер файла: 20 МБ
- Поддерживаемые форматы: MP3, OGG, MP4, WAV

## 💡 Советы для лучшего распознавания

1. **Чистый звук** - меньше фонового шума
2. **Припев** - обычно распознаётся лучше
3. **Громкость** - достаточная громкость для анализа
4. **Длительность** - минимум 5-10 секунд
5. **Качество** - чем лучше качество, тем точнее результат

## 🐛 Troubleshooting

**"Не удалось распознать трек"**
- Попробуйте другой фрагмент песни
- Увеличьте громкость
- Уберите фоновый шум
- Запишите более чёткую версию

**"Файл слишком большой"**
- Максимум 20 МБ
- Обрежьте видео/аудио

**"Документ не является аудио файлом"**
- Убедитесь что отправили именно аудио документ
- Отправьте как голосовое/аудио вместо документа
