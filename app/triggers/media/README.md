# Медиа файлы для фан-команд

## Инструкция

Положите сюда медиа файлы для триггеров.

### Текущие триггеры:

**ivan.mp4** - триггер на имя "Иван"
- Поместите сюда файл `ivan.mp4`
- Бот будет отправлять его при упоминании имени "Иван"

### Поддерживаемые форматы:

- Видео: `.mp4`, `.mov`, `.avi`
- Фото: `.jpg`, `.png`, `.gif`
- Аудио: `.mp3`, `.ogg`

### Размер файлов:

- Максимум 50 МБ для Telegram
- Рекомендуется до 20 МБ для быстрой отправки

## Добавление файлов:

1. Положите медиа файл в эту папку
2. Настройте триггер в `fun_commands/triggers.py`
3. Перезапустите бота
