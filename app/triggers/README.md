# 🎉 Фан-команды

Модуль для триггеров на имена и слова с автоматической отправкой медиа.

## Как это работает

Бот отслеживает все текстовые сообщения и реагирует на определённые слова/имена.

### Текущие триггеры:

#### 1. Триггер "Иван" 🎬
Когда кто-то пишет "Иван" (в любом регистре и склонении), бот отвечает видео `ivan.mp4`.

**Работает на:**
- Кириллица: Иван, ивана, ивану, иваном, иване
- Латиница: Ivan, ivan
- Уменьшительные: Ваня, Вань, Ванечка, Ванюша
- Любой регистр: ИВАН, иВаН, ivan, IVAN

**Источник:** Локальный файл `fun_commands/media/ivan.mp4`

## Добавление медиа файлов

1. Положите файл в папку `fun_commands/media/`
2. Поддерживаемые форматы:
   - Видео: `.mp4`, `.mov`, `.avi`
   - Фото: `.jpg`, `.png`, `.gif`
   - Аудио: `.mp3`, `.ogg`

## Добавление новых триггеров

Отредактируйте `fun_commands/triggers.py`:

```python
"myname": {
    "patterns": [r"\bмоё_имя\b", r"\bmyname\b"],
    "file": "myname.mp4",
    "type": "video",
    "source": "local",
},
```

### Примеры:

**Видео триггер:**
```python
"vasya": {
    "patterns": [r"\bвася\b", r"\bvasya\b"],
    "file": "vasya.mp4",
    "type": "video",
    "source": "local",
}
```

**Фото триггер:**
```python
"photo_trigger": {
    "patterns": [r"\bфото\b"],
    "file": "my_photo.jpg",
    "type": "photo",
    "source": "local",
}
```

**Аудио триггер:**
```python
"sound": {
    "patterns": [r"\bзвук\b"],
    "file": "sound.mp3",
    "type": "audio",
    "source": "local",
}
```

## Регулярные выражения

`\b` - граница слова (чтобы не срабатывать на "Иванов" или "ivan123")

Можно использовать любые regex паттерны:
- `r"иван"` - найдёт в любом месте
- `r"\bиван\b"` - только целое слово
- `r"^иван"` - только в начале сообщения
- `r"иван$"` - только в конце сообщения

## Отключение триггеров

Просто удалите триггер из `TRIGGERS` в `triggers.py` или удалите медиа файл.
