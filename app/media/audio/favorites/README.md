## 🎯 Функционал

### Команды

1. **`/fav`** или **`/избранное`** - открыть список избранных треков
   - Работает в ЛС и в группах
   - Показывает до 100 последних добавленных треков
   - Пагинация по 10 треков на страницу

### Добавление в избранное

**Способ 1: Кнопка на треке**
- При отправке трека ботом под ним появляется кнопка "⭐ Добавить в избранное"
- Нажатие добавляет трек в личное избранное
- Кнопка меняется на "🗑 Удалить из избранного"

**Способ 2: Триггер-символ**
- Ответьте символом `+` на любой аудиофайл
- Трек будет добавлен в избранное
- Сообщение с `+` автоматически удаляется

### Воспроизведение

1. Откройте `/fav`
2. Выберите трек из списка
3. Бот отправит трек:
   - Из кеша (моментально)
   - Или скачает заново и отправит

## 💾 Хранение данных

### База данных: `favorites.db`

**Таблица `favorites`:**
```sql
CREATE TABLE favorites (
    id INTEGER PRIMARY KEY,
    user_id INTEGER NOT NULL,
    platform TEXT NOT NULL,      -- yt, sc, sf
    track_id TEXT NOT NULL,
    title TEXT NOT NULL,
    performer TEXT NOT NULL,
    url TEXT NOT NULL,
    added_at TEXT NOT NULL,
    UNIQUE(user_id, platform, track_id)
)
```

**Что хранится:**
- ✅ Название трека и исполнитель
- ✅ Платформа и track_id
- ✅ URL для повторного скачивания
- ❌ НЕ хранятся файлы музыки

## 🔄 Логика работы

### При добавлении трека
1. Проверка: уже в избранном?
2. Сохранение метаданных в БД
3. Уведомление пользователя

### При воспроизведении
1. Проверка кеша `cache_service.get(platform, track_id)`
2. **Если в кеше** → мгновенная отправка
3. **Если нет в кеше** → 
   - Скачивание через `download_service`
   - Сохранение в кеш
   - Отправка пользователю

## ✅ Преимущества

1. **Экономия памяти** - не хранятся файлы, только метаданные
2. **Быстрая отправка** - используется кеш
3. **Удобный интерфейс** - кнопки + команды
4. **Работает везде** - ЛС и группы
5. **Персональное** - у каждого свой список

## 🔒 Безопасность

- Каждый пользователь видит только свои избранные
- Треки добавляются только владельцем
- Проверка прав при воспроизведении
